# FREE BIBLE READER 0.2.0 — Reading Studio

This release expands the existing reader without changing its five original public Scripture/research databases.

## New capabilities

- Romanian Biblia Liberă in Latin script: accurately labeled draft New Testament, 27 books, 260 chapters and 7,958 source text units.
- Offline narration with actual Windows SAPI/Windows.Media discovery, managed Piper voice downloads and included eSpeak NG fallback. Romanian Mihai is installed through Voice Manager rather than assumed present.
- A controlled player for selections, verses, chapters and lazy book queues, with highlighting, pause/stop, previous/next, speed and volume.
- A selected-text context menu, advanced Unicode search, saved searches/history, private notes/highlights/bookmarks, collections and source-preserving corrections.
- Real PDF and editable DOCX with document settings, native Windows Save As and browser download.
- Guided personal SQLite/CSV/JSON/restricted-SQL/ZIP import, explicit Windows-authenticated SQL Server reads, HTTPS staging, previews/confirmation, checkpointed batch imports and selected-edition SQLite export.
- Nine clear menus and mobile Tools navigation, preserving the existing themes, typography, languages, reading position and three research engines.

## Verified scope

The verification-installer runtime passed 68 reading, 24 legacy acceptance, 13 Studio startup/recovery, eight original bootstrap recovery, 16 library/search, 16 audio and 19 workspace/export GUI checks. Separate native Windows journeys saved an exact Romanian selection to PDF, exported all 36 John 3 verses to DOCX and imported one selected 1,149-row private source edition without changing the original database. Detailed verification distinguishes isolated, native and production stages rather than treating a build as a test.

## Important limits

Biblia Liberă has no Old Testament and remains under revision. Additional Romanian editions can be privately imported; Cyrillic and Latin-script editions are not silently substituted. Research mappings remain edition-specific. Some large searches return explicitly partial results. Arbitrary SQL schemas need user mapping, and sources/import sizes have documented bounds.

Piper models require an initial verified download and remain private user data. Windows voices depend on the machine. Digital WAV and browser playback were tested, while physical-speaker listening remains unverified. Physical mobile devices, native APK/IPA packaging, universal complex-script PDF shaping and independent accessibility certification are not claimed.

The package is unsigned. GPL speech components have their own original notices and corresponding-source asset. Personal databases, notes, voices and recordings are not in the installer or public repository. Historical v0.1.0/v0.1.1 releases remain available.
