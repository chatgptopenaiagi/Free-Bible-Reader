# Included research sources and public derivation

The research modules preserve three independent source-assertion models. They do not certify theological truth, historical transmission or equivalence between editions.

- Visual graph: `https://github.com/trekhleb/bible-cross-references`, commit `23bf0908858c949e519abe7a4ce7f4492f5fb3ba`; original code MIT, supplied OpenBible graph attribution CC BY4.0. Original signed votes, ranges, source records and remaps retained. See `research-visual-MIT.txt`.
- Aggregate graph: `https://github.com/neuu-org/bible-crossrefs-dataset`, commit `8aa012820f5881a787e87d71005a22f52844c4fb`. NEUU declares its consolidation/data/scripts CC BY 4.0. Its source documentation identifies the underlying historical Torrey TSK work as public domain; that is distinct from subsequent electronic curation and packaging. The bundled SoulLiberty source distribution includes a GPL 2 notice, retained in `research-tsk-source-GPL2.txt` for its source/code/curation distribution. These are separate provenance layers; no blanket MIT claim or new license assignment is made for all bundled data. Original directed assertions, source record locators and missing-vote distinctions remain intact; no generated logical inverses.
- Phrase graph: `https://github.com/CrossReferences-org/bible-cross-references`, commit `a80ab3d8bcc4ed53c86bae2e2a5ef183b9316653`; repository data attribution CC BY4.0. This public SQLite is a **derived subset**, including native KJV/BSB/AOV only. S21 anchors/locations/target groups/source entries and all nested S21 fields in remaining JSON were removed. An unrelated private mapping row was removed. VACUUM was applied only to this new copy. Source-file SHA values identify the original upstream inputs; they are not hashes of redacted record bytes or the derived SQLite file. The derived file has its own separate SHA in the public [release manifest](https://github.com/chatgptopenaiagi/Free-Bible-Reader/blob/v0.1.0/data/research-release.json).
- Reference parser: `https://github.com/openbibleinfo/Bible-Passage-Reference-Parser`, commit `15c9f0993267014d9d3aa81256b9ff5565e58856`; MIT notice is retained in `research-parser-MIT.txt` and the vendor directory. The source commit subject mentions4.1alpha while its actual package metadata says4.0.0; no different released binary is claimed.

Native phrase text and scalar positions belong to their named source edition. `eng-kjv` is only an explicit public compatibility alias for `crossreferences:KJV`; it is not a link to a private corpus or an immutable external-edition mapping. BSB/AOV queries use the phrase engine only; the other graphs have no certified mappings to those editions. The AOV duplicate-sort coordinate remains unresolved with text withheld.

The four shipped research SQLite files are read-only runtime assets. The reference seed contains structural parser metadata only, without prior user resolutions, private edition identities or cached private mappings. No private source package, original master corpus, SQL service, private filesystem route or runtime configuration is required.

The public visual database also has a narrowly documented metadata derivation: its archive locator was changed from an absolute private build path to the original repository-relative `data/raw/openbible-cross-references.zip`. Graph rows, original archive/member/record hashes, text and source assertions were not changed. Only the new public copy was vacuumed to remove the obsolete host path; its current public database SHA is recorded separately from the original exact-copy SHA.

Source checkouts may omit the large research databases from Git. A separately published asset ZIP can restore them using the explicit standard-library command `python engines/fetch_research_assets.py --release-zip research-assets.zip --sha256 EXPECTED_ARCHIVE_SHA256`. The command requires a real externally supplied archive checksum; no fictitious published release URL is embedded and no download runs during normal reading.
